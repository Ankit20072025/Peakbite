# Peakbite

Peakbite is a student protein-bar brand built for a digital marketing course.
Static website: `index.html`, no build step.

## Features
- Product, flavours and pricing with a working cart and coupons
- "Compare with any bar" tool (Open Food Facts API)
- WhatsApp ordering, optional Razorpay checkout, Formspree newsletter
- UTM and Google Analytics event tracking for campaign reporting

## Setup
Open `index.html` and edit the `CFG` block near the bottom:
`WHATSAPP`, `RAZORPAY_KEY`, `FORMSPREE_ID`, `GA_ID`.

## Deploy
- Vercel: import this repo, Framework Preset "Other", no build command.
- GitHub Pages: Settings > Pages > Deploy from branch > main > / (root).
